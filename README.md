# Aura Canvas

Build a smooth 3D interactive website for an Ai social media management company. Build a fully responsive, high-performance 3D landing page using React, Next.js, Three.js, React Three Fiber (R3F), Drei, Framer Motion, GSAP, and Tailwind CSS.

Requirements:

* Full-screen animated hero section with a floating 3D object.

* Interactive mouse movement with smooth parallax effects.

* Scroll-triggered animations using GSAP ScrollTrigger.

* Dynamic lighting, soft shadows, bloom, and ambient occlusion.

* Animated particle background with 3D stars.

* Glassmorphism navigation bar with blur effects.

* Smooth page transitions using Framer Motion.

* Floating cards that react to mouse hover.

* Interactive call-to-action buttons with magnetic hover effects.

* Dark/light theme toggle with animated transitions.

* Responsive design for desktop, tablet, and mobile.

* Lazy loading for 3D assets.

* Optimize rendering to maintain 60 FPS.

* SEO optimized with Next.js metadata.

* Include loading screen with animated progress indicator.

* Add subtle sound effects that can be muted.

* Code should be modular, reusable, documented, and production-ready.
